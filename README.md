# towerdefense

Greenfield mobile/web game workspace.

## Design foundation

The starting product plan lives in [`docs/viral-game-plan.md`](docs/viral-game-plan.md): Flappy Bird–era viral pattern analysis, a comparative hit matrix, seven shared design patterns, and six brainstormed concepts (A–F).

**Open decision:** pick a concept (recommended: **A “Almost”** or **B “Daily Dare”**) or a hybrid before implementing a core loop. The repo name is a placeholder until that choice lands.

## Build order (from the plan)

1. Choose concept A–F (or hybrid)
2. Design the shareable artifact first
3. Ship a 3-second one-input loop with instant restart
4. Add near-miss feedback
5. Playtest retry rate + unprompted sharing
